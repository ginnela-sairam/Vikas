# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through
[GitHub's security advisory reporting page](https://github.com/ginnela-sairam/Vikas/security/advisories/new)
instead of opening a public issue. Include the affected version, relevant
commands or inputs, and steps to reproduce when it is safe to do so.

Please do not include proprietary RTL, credentials, or other sensitive material
in a report.
